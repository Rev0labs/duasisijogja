Integrasi Google Apps Script (Web App URL)

Masukkan Web App URL yang didapatkan setelah melakukan deploy Google Apps Script dari spreadsheet Dua Sisi Jogja.

Cara Mendapatkan Web App URL:
  1. Buat Google Spreadsheet baru di Google Drive Anda.
  2. Klik menu Extensions (Ekstensi) → Apps Script.
  3. Paste isi file Code.gs yang sudah disediakan.
  4. Klik tombol Deploy → New deployment.
  5. Pilih tipe Web app, atur Who has access ke Anyone, lalu klik Deploy.
  6. Salin URL Web App yang muncul, lalu paste di kolom atas dan klik Simpan.
Semua perubahan tersimpan di cache lokal & Google Sheets saat Anda klik Simpan.
